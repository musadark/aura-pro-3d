# AURA PRO — первый рабочий 3D-сайт

Адаптивная презентация наушников по мотивам прикреплённого видео. Это запускаемый прототип с оригинальной упрощённой геометрией, а не точная копия модели из ролика. Бренд AURA и тексты — демонстрационные.

## 1. Открыть в VS Code

Распакуй `aura-site.zip`, затем выбери **Файл → Открыть папку → aura-site**. Если работаешь в уже подготовленной папке проекта, распаковка не нужна.

Нужен установленный Node.js версии **22.13 или новее**. Открой **Терминал → Создать терминал** и проверь:

```powershell
node --version
```

## 2. Установить и запустить

В терминале Windows:

```powershell
npm.cmd ci
npm.cmd run dev
```

На macOS/Linux те же команды без `.cmd`. Установка выполняется один раз; для неё нужен интернет. При следующих запусках достаточно `npm.cmd run dev`.

Открой **http://localhost:5173**. Если порт занят, используй `npm.cmd run dev -- --port 5174` и адрес из терминала. Не открывай `.tsx` двойным щелчком: сайт запускается через локальный сервер. Чтобы остановить сервер, нажми `Ctrl+C` в терминале.

Шрифт Manrope загружается из Google Fonts. Если интернет недоступен, используется системный шрифт. Сами модели и фактуры создаются локально, без внешних файлов.

Разрешение 3D автоматически ограничивается размером окна и снижается при устойчивых просадках кадров. Текст и кнопки при этом остаются в исходном разрешении. Движение за прокруткой и за курсором сглаживается.

## 3. Что попробовать

- Прокручивай вниз и обратно: наушники меняют положение, появляется светлая сцена, затем кейс на подиуме.
- Во второй сцене от наушников расходятся тонкие звуковые волны. В тёмных сценах медленно плывут частицы; в светлой они исчезают. В режиме «Статика» оба эффекта останавливаются.
- Нажми номера 01–04 слева (на телефоне справа), чтобы перейти к сцене.
- Вверху переключи **Движение / Статика**. В статике сцены переключаются без промежуточного пролёта. Если при открытии стоит «Статика», нажми её: движение включится даже при системной настройке уменьшения анимации. Явный выбор сохраняется при обновлении этой вкладки.
- В последней сцене нажми **Рассмотреть AURA PRO**, выбери графит/жемчуг и поворот, затем **Посмотреть результат**.
- Сузь окно: модель и текст перестроятся для телефона.

## 4. Где менять сайт

| Файл | Что в нём |
| --- | --- |
| `components/experience.tsx` | Тексты, меню, четыре сцены, кнопки, диалог настройки модели. |
| `app/globals.css` | Шрифты, размеры, цвета, расположение блоков и мобильная версия. |
| `lib/aura-model.ts` | Геометрия наушников и кейса, материалы, точка вращения крышки. |
| `lib/aura-scene.ts` | Свет, камни, подиум, камера, сценарий прокрутки, обработка изменения размера. |
| `lib/aura-effects.ts` | Звуковые волны и частицы. Их яркость, количество и скорость можно настроить отдельно. |
| `public/poster.svg` | Запасное изображение, если WebGL недоступен. |
| `app/layout.tsx` | Название страницы, описание и язык. |
| `VIDEO-ANALYSIS.md` | Подробный разбор исходного ролика и план следующих этапов. |
| `VERIFICATION.md` | Что проверено и ограничения первой версии. |

Остальные служебные файлы относятся к шаблону React/Vinext и сборке; для первых изменений их трогать не нужно.

## 5. Первая небольшая правка

1. Открой `components/experience.tsx`.
2. Найди строку `Тише мир.` и замени заголовок своим.
3. Сохрани файл. Браузер обновится автоматически.
4. В `app/globals.css` найди `--accent` и измени цвет маленьких акцентов.
5. Проверь широкое и узкое окно, прежде чем менять следующую деталь.

## 6. Как устроена анимация

На странице длинный блок `.experience`, внутри которого сцена `.stage` удерживается на экране через `position: sticky`. Пройденная часть блока преобразуется в число от 0 до 3. Это положение на шкале из четырёх сцен.

В `lib/aura-scene.ts` массивы `desktop` и `phone` задают положения продукта на этой шкале. Между строками значения плавно смешиваются:

- `x`, `y` — положение композиции;
- `s` — масштаб;
- `ry`, `rz` — поворот в радианах;
- `gap` — расстояние между наушниками;
- `ly`, `ry2` — высота левого и правого наушника.

Пример: уменьши `s: 1.6` в первой строке `desktop` до `s: 1.35`, чтобы сделать продукт меньше на первом экране. Меняй по одному значению, иначе сложно понять причину результата.

Поворот кейса, открытие крышки, движение камеры, прозрачность текстов и цвет фона рассчитываются от той же шкалы. JavaScript не перехватывает колесо мыши или жесты прокрутки. Системная настройка уменьшения движения задаёт начальный режим; явный выбор кнопкой на странице имеет приоритет.

## 7. Проверить сборку

```powershell
npx.cmd tsc --noEmit
npm.cmd run build
```

Сборщик может сообщить, что модуль 3D больше 500 КБ: это предупреждение о размере, не ошибка сборки. 3D загружается отдельным модулем. Проверка готового варианта локально:

```powershell
npm.cmd start
```

Открой адрес, который появится в терминале. `npm start` запускает локальный режим Cloudflare Worker; это не публикация сайта.

## Что дальше

Первый этап выполнен: есть исходники, адаптивная композиция и рабочая анимация. Следующий наиболее заметный шаг — заменить условные наушники и кейс качественным GLB, затем настроить фактуры камней, контактные тени и промежуточные ракурсы. Подробности и критерии — в `VIDEO-ANALYSIS.md`.

Сайт не принимает заказы. Реальные характеристики, цена, форма заявки и оплата в эту демонстрацию не включены.

## GitHub Pages

Для размещения без постоянно включённого компьютера добавлена отдельная статическая сборка. Она использует ту же сцену, тексты и стили, что и локальная версия:

```powershell
npm.cmd run build:pages
npm.cmd run preview:pages
```

Готовые файлы находятся в `dist-pages/`. Относительные пути поддерживают адреса вида `username.github.io/repository/` и собственный домен.

Workflow `.github/workflows/pages.yml` собирает и публикует сайт после отправки изменений в `main`. В настройках репозитория **Settings → Pages → Source** выбери **GitHub Actions**. Секреты или дополнительные ключи для этого workflow не нужны.

Основной вход для статической версии — `index.html` и `pages-entry.tsx`; конфигурация — `vite.pages.config.ts`. Серверная сборка `npm run build` сохранена отдельно.
